# 项目简述模板

- 项目名称与负责人：
- 规范版本与commit：
- 一句话卖点／解决的问题：
- 用户及使用场景：
- 一分钟核心循环：用户做什么、收到什么反馈、再做什么决定？
- MVP范围与明确不做：
- 最小验证样例：先把哪一个对象或任务做通？
- 可观察验收结果与停止／改向条件：
- 规则与边界：成功、失败、重复输入、暂停、取消、恢复、异常。
- 平台、输入、语言、引擎与在线／离线要求：
- 2D／3D／2.5D选择与理由：
- 时间、预算、外部服务与权限约束：
- 真人验证：对象、问题、观察任务、无解释首体验、求助／退出／重试记录、复测：
- 每轮探索时间／费用上限、到期继续／改向／停止决策：
- 商业化成本／收益假设与验证计划（不适用写N/A）：
- 切片代表性、单位生产时间、返工成本与产能：
- 性能、可读性、内容抽测预算与未验证假设：
- 唯一批准基线、批准人及变更记录位置：
