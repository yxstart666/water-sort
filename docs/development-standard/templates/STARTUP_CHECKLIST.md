# 开工核验模板

首次进入项目完整填写；续接或更换AI仅填变化、未决风险与环境差异，引用已核实基线。状态只用：已核实／未核实／阻塞／N/A并说明理由。

- 规范版本、commit与实际读取路径：
- 项目文档版本、批准基线与当前交接：
- 项目仓库、分支与commit：
- 实际核实的代码、资产、构建、测试、部署状态及证据：
- 当前环境、引擎、依赖、工具／MCP及最小连接检查结果：
- 模型与工具实际选择：
- 产品原型、视觉、资产、在线服务、隐私、发布等流程的适用性：
- 3D：需要／不需要；理由；需要时专项流程是否已读取：
- 3D工具鉴权／格式／费用／批准预算／性能目标：
- 文件归属、接口与集成负责人：
- 已发现缺口、阻塞、负责人和下一步：
- 首个最小里程碑、交付物、通过条件与证据：
- 需用户决定的事项：

不可访问不等于已读取；不需要不等于遗漏；未测试不等于通过。收费操作需批准额度，密钥不填写在此表。
