# 交接报告模板

- 项目、日期、负责人／验收人：
- 规范版本与commit、项目基线：
- 仓库、分支、提交及远程状态：
- 环境、引擎、依赖、实际模型／工具：
- 安装、构建、运行及测试命令：
- 构建包校验值、对应测试报告与签名所有权／备份策略：
- 当前交付与证据：
- 完成状态逐项说明：已写／已测试／已提交／已推送／已部署／目标设备已运行／已发布。
- Mock、Stub、占位资产及未接服务：
- 目标设备测试、真人反馈与尚未验证项：
- 资产源文件、授权、3D专项验收位置或N/A理由：
- 风险、缺陷、阻塞、接受人：
- 回滚与存档恢复：
- 下一步、责任人、依赖及检查点：
- 独立接手复现结果：

阶段报告、变更单和缺陷记录字段见规范正文“直接复用的执行模板”。不要把密钥、令牌或生产凭据加入交接包。
