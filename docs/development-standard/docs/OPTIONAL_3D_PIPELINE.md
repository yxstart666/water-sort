# 可选 3D 资产流程

适用版本：V1.2。由主规范准入判断触发；无需3D时记录N/A，不执行生成。

本流程仅在项目确需3D模型时适用。Hyper3D MCP是可选工具，不是必选供应商；无法使用或不合适时，可评估其他授权资产或制作方式。模型生成不保证可商用、可拆件、已绑定或已有正确动画。

### 入口检查与小样生成

确认用途、目标引擎、导入格式、最低设备、性能预算、模型数量与品质。核实当前环境中的MCP连接、鉴权、可用操作、格式及费用；明确单次与累计预算，只在已批准额度内执行收费任务。鉴权失败、费用不明或超预算时停止相关调用。

先批准设定图与资产规格，再生成一个代表性小样。记录prompt、参考图授权、参数、服务与任务ID、时间、下载文件、资产版本和费用。轮询生成状态不重复提交收费任务；失败后先确认任务结果和费用，再按授权范围重试。

### 技术检查与必要修正

检查拓扑、面数与目标设备预算、UV、PBR贴图与材质、法线、尺寸单位、轴向、枢轴和部件独立性。需要动作时检查骨骼、权重、蒙皮、动作兼容及重定向；拆装交互要求对应部件真实独立，不能只在概念图中看似可拆。

使用Blender等合适工具进行必要清理、重拓扑、减面、UV／材质修正、部件分离和绑定。无法达到要求时修改输入、换方案或人工修复，不把未处理模型直接列为完成。保留可编辑源文件与导出版本。

### 真实导入与验收后扩量

在目标引擎实际导入，核对材质、透明、光照、碰撞、比例、朝向、锚点、动作与互动。运行最低目标设备的性能检查，记录帧率／资源占用等项目指标与条件。小样不通过则返工，不批量生产同类问题资产。

通过后固定命名、预算、导出与集成规范，再批量生成；每批复查一致性与回归。保存来源、许可证／商业使用条款核验日期、版本与验收证据。提示词和参数可入库，密钥与令牌不得入库；模型文件是否入库按授权及仓库容量策略决定。
