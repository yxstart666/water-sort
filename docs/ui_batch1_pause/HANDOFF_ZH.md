# 倒瓶子 UI 第一批：暂停弹窗真实资源复用包

## 交付用途
本包交付 38 张原有独立 PNG、定位/状态契约、中文/英文字体及许可，用来替换当前订单玩法中 `Panel + StyleBoxFlat` 的临时暂停窗口。不是只交概念图，也没有重新生成一套按钮。素材逐文件 SHA-256 与云端货运项目来源一致。

目标工程：用户现有“倒水瓶”订单玩法工程。`order_view.gd`、`order_hud.gd` 及其他本地未提交修改都必须保留；本包没有这两个脚本，也没有自动覆盖/安装脚本。先备份或提交本地变更，再按缺失清单合入资源。有同路径不同哈希时先保留并报告冲突，不覆盖。

## 目录与权威顺序
- `assets/`：可用资源，保持原项目相对路径。合入项目同名根目录后，`res://assets/...` 路径成立。
- `ASSET_MANIFEST.json`：每个资源的字节数、SHA-256、尺寸、alpha 范围、透明像素和定位/状态来源。
- `contracts/DEPENDENCY_RESOLUTION.json`：旧 `reuse://` 引用到实际 `res://` 路径的完整解析表，38 个依赖均已带入且校验通过。
- `contracts/PAUSE_RUNTIME_CONTRACT.json`：本批推荐使用的基础弹窗交互与适配契约。
- `contracts/reference_code/`：旧组件示例，只读参考，不能整体复制到工程脚本目录。
- `references/water_gameplay_target.png`、`water_pause_target.png`：新倒瓶子完整效果图，只作视觉参考；不是透明切片，也不应作为整个可点击游戏页的背景。
- `references/contact_sheet_*.jpg`：资源清点图，不是运行素材。

优先使用原生独立资源与明确布局契约。新 AI 效果图的框体缩放、分隔线、标题比例与旧素材并非逐像素一致；本包不声称从新图恢复了隐藏图层。先恢复已批准的组件质量，不让程序员临时重画。若要求新效果图逐像素一致，应由美术追加修订坐标/素材，不自行拉伸烘焙文字。

## 第一阶段应实现的暂停窗口
从订单局点击设置或平台返回键进入暂停，所有订单/倒水/交付状态按现有安全边界暂停，不能重新发货、扣费或生成新局。

内容：游戏暂停 / Paused；音乐、音效独立 ON/OFF；语言；继续游戏；重玩本关；主页选关；右上关闭。右上关闭等同继续，不销毁当前局。

“主页选关”必须真的进入选关页。若现有工程只有主页，需另行提供对应文案，不能把写着选关的旧按钮悄悄绑到另一目的地。

“重玩本关”先确认；取消回暂停，确认走原订单局重开接口。是否扣体力由现有业务决定，不由此美术包改变。音乐/音效/语言绑定同一份持久设置，不另建第二套。

语言弹层展开时只接收两种语言选项。点外侧只关闭语言列表并消费本次点击，不穿透到继续/重玩。Escape/安卓返回顺序：语言列表→暂停窗口→当前局，不能一下退到主页。

## 字体、透明与状态
本包包含 NotoSansCJK-Bold.ttc、NotoSans-Bold.ttf 及原许可。它们保持原字体包路径，不要求替换当前工程已存在且哈希一致的字体。中英不要共用中文字宽硬挤。标题/主要按钮已有中英烘焙素材，直接换对应版本，不在旧文字上叠字。

38张PNG都有真实透明区域；contact sheet已查看边缘。个别旧正文文字切图仅适合在原奶油底和原坐标使用，透明不代表能放任意背景；优先沿用旧运行逻辑的真实字体正文。保持 straight-alpha 合成，不再手工去白，不以发光描边遮住锯齿。

按下/焦点/禁用采用 `interaction_states.json` 既定参数，不要求新PNG：按下RGB×0.92且不改布局；键盘焦点边框；禁用变灰且不响应输入。它们是已定义渲染状态，不是宣称已有独立五态贴图。

## 适配订单工程，不搬货运业务
- 将可复用外观封装为独立 PauseDialog 视图，向 `order_view`/上层控制器只发送 resume、restart_requested、level_select_requested、preference_changed。
- `order_hud` 只保留设置入口；不要复制整份 `restore_view.gd`，它耦合货运队列/机器人/收集区。
- 可参考 `preview_art.gd` 的白名单和定位、`pause_state_art.gd` 的OFF切换、`modal_host.gd` 的遮罩层级。reference_code不是直接运行入口，有原项目依赖。
- 原 `settings_guide_entry` 包的“玩法说明”按钮/路由含货运教学旧引用。本批基本暂停不启用它；要增加倒瓶子教学，应绑定现有订单教程，不能打开货运教程，也不能增加一个无效入口。
- 暂停控制应沿用本地现有动画事务边界；恢复后不可重复加塞/收单/完成回调，不能用UI刷新重置棋盘。

## 验收清单
1. 中英 ON/ON、OFF/OFF、ON/OFF、OFF/ON 共8种基础状态，独立设置生效且重启保存。
2. 中英语言展开、外侧点击、Escape，均无穿透与重复弹窗。
3. 倒水/加塞/收单期间打开设置，恢复后瓶子、订单、步数和计时保持正确。
4. 重玩确认→取消/确认；选关返回；双击继续/重玩不重复执行。
5. 360×640、390×844、540×960、1080×1920逻辑/设备映射：字体不裁、触控>=44逻辑像素、遮罩覆盖全屏、英文不溢出。
6. 与新效果图同一游戏背景对比，不能使用货运场景整图做暂停背景。
